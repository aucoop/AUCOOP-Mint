# What's on the laptop

![The desktop](../assets/desktop.jpg)

Everything lives in the taskbar along the bottom, and the button on the far left opens the menu, same as the Start button people are used to.

## The apps

**Google Chrome** is the browser, and it's the default for anything that opens a web link.

**Word, Excel and PowerPoint** are OnlyOffice underneath. The names and icons are deliberate: someone who spent ten years in a Windows computer lab shouldn't have to learn that "Writer" means Word. They open and save `.docx`, `.xlsx` and `.pptx`, plus the OpenDocument formats.

**Files** is the file manager, and the blue arrow is the **Software Manager**, where thousands of free apps live, including everything on Flathub.

The two desktop icons are AUCOOP Welcome, which you can reopen whenever you like, and the offline AI assistant if it was installed.

## The two offline things

A laptop in a school with no reliable connection is still useful, as long as you put something in it before it leaves. That's the idea behind both extras.

**Offline Wikipedia (Kiwix)** reads `.zim` files: compressed snapshots of Wikipedia, Wikibooks, Project Gutenberg, Khan Academy and others. Install the reader from AUCOOP Welcome, then get the content itself on a good connection or from a USB stick. A full Wikipedia in one language runs to several gigabytes; smaller "no pictures" editions are far lighter and still answer most homework questions.

**The offline AI assistant** runs a language model on the laptop, with no account, no cloud and no data leaving the machine. It has [its own page](offline-ai.md).

## Updates

Mint's own Update Manager keeps working normally, since AUCOOP Mint doesn't replace it. The shield icon in the corner tells you when updates are waiting.

## Changing the language

The system language comes from the Mint install. To change it: menu, then Preferences, then Languages. AUCOOP Welcome and the installer follow that setting automatically for English, Spanish, Catalan, French and Portuguese.
